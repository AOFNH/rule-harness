# docs/ Rules

Project-level rules for every versioned file under `docs/`, including
`docs/design/` and `docs/iterations/`.

- Write all prose in English, whatever language the conversation with the user
  uses. Versioned files here contain no CJK characters or full-width
  punctuation.
- Keep established identifiers verbatim: class, method, module, table, and
  column names, config keys, commands, paths, and version strings.
- These rules replace the root bootstrap rule that Chinese specifications,
  design documents, plans, and review notes use Chinese prose. A project-level
  rule ranks above a public user-level rule in the precedence order of the root
  `AGENTS.md`.
